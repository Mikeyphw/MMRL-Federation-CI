# N05G native hosted federation harness

Private, isolated GitHub Actions coordinator. The original local coordinator history is not included. The config is a portable projection of the source-bound coordinator and the manifest contains only allowlisted source/graph digests. On a clean Ubuntu runner, check out the three exact public source commits without credentials, reconstruct the reviewed child branch/upstream/remote identity, compare native portable source/graph digests, freeze a fresh strict-local lock, verify FRX-04/08 and the frozen DAG, and execute the native federation command. The runner uses Java 21, Android SDK 36 and pinned Devtool. A report and durable checkpoint are retained in a private workflow artifact. Neither native parent success nor this workflow is independent CI qualification; the exact artifact, run/attempt and six actual node outcomes must be reviewed separately. No releases, signing keys, APK publication, physical device operations, Git pushes from CI, source-lock weakening or SSH worker fallback.
